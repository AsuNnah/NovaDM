Import reads the bookmarks of Chrome, Edge, Brave, Vivaldi and Firefox straight from this PC (a copy is read; nothing is sent anywhere), or a bookmarks file. Export saves an HTML file that all of them import. The star in the address bar (Ctrl+D) adds the page you're on; drag bookmarks on the bar or here to rearrange them. Private tabs can use bookmarks too, but never add history.
